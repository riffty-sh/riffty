# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| `0.2.x` | :white_check_mark: |
| `< 0.2.0` | :x: |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/jonatashackathons/riffty/security/advisories/new) rather than opening a public issue.

We will acknowledge receipt within 48 hours and provide a remediation timeline once the report is triaged.
